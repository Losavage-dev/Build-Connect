# BuildConnect — Roadmap

## Сейчас (MVP — к защите, июнь 2026)

- Каталог verified компаний, тендеры, услуги, материалы, promo feed  
- Заявка + realtime чат + статусы + отзывы  
- Верификация документов + модерация + жалобы  
- Rule-based рекомендации (`user_events`)  
- Шаблоны договоров (client-side export)  
- Deploy: Vercel + Supabase Cloud  

---

## v1.1 (1–2 месяца после защиты)

| Feature | Зачем |
|---------|--------|
| Поле **БИН** в компании + отображение модератору | Доверие, согласование с дипломом |
| **Email-уведомления** (Edge Function) | Не пропускать заявки |
| **Пагинация** списков | Масштаб каталога |
| **Shortlist** компаний у заказчика | UX выбора |
| **Сравнение** 2–3 компаний | ✅ Каталог → «В сравнение» → `/catalog/compare` |
| **Модалка отзыва** после завершения заявки | ✅ `PostDealReviewDialog` в чате |
| Custom domain `buildconnect.kz` | Бренд |

---

## v2 (6+ месяцев)

| Feature | Зачем |
|---------|--------|
| **Компания-заказчик** (ТОО/ИП) + тендер от юрлица | Чистый B2B |
| **Отзывы между компаниями** (заказчик ↔ подрядчик) | Симметричное доверие |
| Публичные профили пользователей (`user_reviews` в БД — задел) | Репутация контактных лиц |
| Интеграция **data.egov.kz** / проверка BIN | Автоверификация |
| **KATO** коды вместо только названия города | Точный geo-filter |
| ML-рекомендации | Персонализация |
| Escrow / оплата | Monetization |
| eGov подпись | Юридическая сила |
| Mobile (React Native / PWA) | Охват |

---

## Позиционирование

**Не** «дешевле всех», а **«проверенный подрядчик + прозрачная сделка в одном месте»** — ядро CustDev и конкурентное отличие от Stroyka.kz / B2BMap.
