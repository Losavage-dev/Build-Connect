# QA Bugs — BuildConnect

Заполняется в **Фазе 2**. Формат строки в таблице ниже.

| ID | P | Модуль | Шаги | Ожидание | Факт | Статус |
|----|---|--------|------|----------|------|--------|

**Статусы:** `open` · `fixed` · `wontfix` · `deferred`

---

## Шаблон новой записи

```markdown
### BUG-001 — краткое название
- **P:** P0 / P1
- **Шаги:** 1… 2… 3…
- **Ожидание:** …
- **Факт:** …
- **Статус:** open
```
